
Backend API for **Chuks Kitchen Food Ordering & Customer Management System**.

## RUN THE FOLLOWING COMMAND TO BE ABLE TO TEST OUT THIS PROJECT ON YOUR COMPUTER
npm init -y
npm install express

This system allows customers to register, browse meals, add items to cart, place orders, and track order progress.  
Admins can manage food items and update order statuses.

---

## 📌 Project Overview

Chuks Kitchen is digitizing its food business to allow customers to:

- Sign up and verify accounts
- Browse available meals
- Add meals to cart
- Place orders
- Track order status lifecycle

This backend system models the complete flow and business logic behind the platform.

---

## 🛠 Tech Stack

- Node.js
- Express.js
- REST API Architecture
- In-Memory Storage (for demo purposes)

---

## 🧠 System Architecture

The system consists of:

- User Management
- Food/Menu Management
- Cart System
- Order Processing Engine
- Order Status Lifecycle Management
